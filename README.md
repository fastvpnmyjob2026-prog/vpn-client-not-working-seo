## FAQ

### Why is my vpn client not working even though it says “Connected”?
Most of the time it’s DNS or routing. Reconnect once, then switch protocol/region. If you use Kill Switch, confirm it isn’t blocking traffic after a drop.

### What’s the fastest fix for “stuck connecting”?
Change server region first. If it still hangs, restart the client, then reboot once to reload the network driver stack.

### Will a Kill Switch break my internet?
It can—by design—when the tunnel drops. If the app crashes, the Kill Switch can leave rules behind. Disable it, reconnect cleanly, then re-enable.

### Does this keep logs?
The client follows a **No-Logs policy** and is built with a privacy and security focus.
